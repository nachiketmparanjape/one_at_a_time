## Purpose

End task-list paralysis: you never face your whole list, only the next right
thing. Open the app, get one task, do it — the list manages itself in the
background.

## V1 scope (as imported 2026-10-09)

- One-thing focus view with swipe (accept / dismiss to next)
- Smart picker: urgency + due dates + actionability scoring + weighted random
- Add tasks (text, due date, urgent flag); all-tasks list; archive; stats
- Google + anonymous auth with account linking
- Mobile-first PWA (installable, offline shell, haptics)

Founder has not set v1 scope in-studio yet — the above describes the app as
imported. Scope changes go through sprint planning.

## Explicit non-goals (imported state; founder to confirm)

- No projects, tags, or priorities UI — the picker owns ordering
- No calendar integration
- No collaboration / shared lists
- No recurring tasks
- No AI features yet (the scorer is heuristic, not LLM)

## The one-line test

A user with 40 overdue tasks opens the app, gets handed one doable thing,
and does it instead of closing the app. Anything that doesn't serve that
moment is out.
